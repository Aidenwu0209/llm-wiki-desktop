# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful, constructive, and harassment-free for everyone.

## Expected Behavior

- Be kind, patient, and specific.
- Assume good intent while still naming risks clearly.
- Keep feedback focused on code, docs, tests, safety, and user outcomes.
- Respect privacy boundaries around user documents, credentials, and unpublished research.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Dismissing safety, privacy, or consent concerns.
- Misrepresenting test results, live provider calls, external users, or contributor status.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants who violate this code of conduct. Reports can be sent privately to the maintainers through the repository owner's GitHub profile or GitHub moderation tools.

## Attribution

This is a concise conduct policy inspired by standard open source community guidelines.
